## 第 1 章 · 装大脑（AstrBot）

**视频原流程**

1. 浏览器进 AstrBot 发布页，双击安装包
2. Windows 弹蓝色窗口（SmartScreen）→ 点「更多信息」→「仍要运行」
3. 安装位置**默认**就可以
4. 装好打开启动器 → 左侧「**高级**」→ 打开「**中国大陆一键加速**」
5. 进「**组件管理**」→ 把**三个组件**都点一遍「下载」→ 等进度条走完
6. 点「**创建实例**」→ 名字填「我的 astrbot」→ 版本选**最新** → **端口留空** → 点「部署」
7. 等部署成功（会花一些时间）
8. 部署成功会**弹出一组后台默认账号和密码** → 抄到记事本

**本机实际**

| 项 | 值 |
|---|---|
| 安装位置 | `<ASTRBOT_INSTALL>`（视频说默认即可，本机装在了 E 盘） |
| 启动器 | `astrbot-launcher.exe` |
| 实例版本 | **v4.29.4** |
| 三个组件 | Python **3.10.22** + **3.12.16**、Node **v26.13.0**、uv **0.13.6** |
| 默认账号 | `astrbot` |
| 默认密码 | 首次启动生成 **24 位**随机串，大写+小写+数字各至少一个 |

视频没细说密码机制，这里补一句：`dashboard.password` 存的是 PBKDF2-HMAC-SHA256（60 万次迭代、16 字节盐）哈希，所以那串明文只在弹窗出现一次。丢了用环境变量重设：

```powershell
$env:ASTRBOT_DASHBOARD_INITIAL_PASSWORD = "新密码"
```

详细步骤见 [install/astrbot.md](install/astrbot.md)。

## 第 2 章 · 装登 QQ 的工具（NapCat）

**视频原流程**

1. 搜索框搜 `napcat` → 进发布页
2. 找带 **OneKey** 的 **Windows 一键包**
3. 下载完是一个压缩包 → 右键「全部解压缩」→ 目录改到 **D 盘的 NapCat 文件夹** → 点提取
4. 解压后双击里面的 **`NapCatInstaller.exe`**
5. 安装器会自动去腾讯官网下 QQ，再把 NapCat 环境配齐
6. 界面显示「安装完成」就搞定了

视频特意说：**它装的是给小号专用的 QQ，不会影响你平时电脑挂的大号**。

**本机实际**

| 项 | 值 |
|---|---|
| 安装位置 | 桌面的 `NapCat.52230.Shell`（视频建议 D 盘，本机放桌面） |
| 内置 QQ | **9.9.33-52230** |
| 安装器 | `NapCatInstaller.exe` |
| 发布页 | https://github.com/NapNeko/NapCatQQ/releases |
| 资产名 | `NapCat.Shell.Windows.OneKey.zip` |

视频没说但要注意：解压路径**不能带中文或空格**，否则注入 hook 那一步容易失败。

详细步骤见 [install/napcat.md](install/napcat.md)。

## 第 3 章 · 申请两个 API Key

**视频原流程**

准备：DeepSeek 开放平台账号 + 火山引擎账号。

**DeepSeek 的 key：**

1. 浏览器搜「DeepSeek 开放平台」，认准官方结果
2. 手机号登录 → 进控制台
3. 先看一眼充值页面，**充一点就够尝试**
4. 左侧菜单「**API keys**」→ 创建一个新的 key
5. 名字随便填（视频填的是「大肥鱼」）
6. 这串字符就是 API key，**只会完整出现一次** → 点复制 → 粘到记事本

**豆包语音的两样：**

1. 火山引擎的豆包语音控制台里拿 **app id** 和 **access token**
2. 视频特意提醒：**火山方舟那边的 API key 是用不了的**，别拿错
3. 两样都存到记事本

视频的原话：API key「就像一张门禁卡，程序拿着它去调模型，按照用量扣钱。别人拿到你的 API key，就相当于能花你的余额，**一定要自己保存好，千万不要发给任何人**」。

豆包语音的计费：按时长收钱，每回一条语音两三秒，算下来**几分钱**。缺点：发语音时生成会慢一点，大概要等 **20 多秒**。

**本机实际**

| 项 | 值 |
|---|---|
| DeepSeek key | 走自建中转，**地址与域名不公开**，配置里写 `<YOUR_API_BASE>` |
| 语音 | **没用豆包**，换成本机 Breeze-TTS-2 —— 这是视频之外的选择，见 [../README.md](../README.md) |
| 额外接入 | nvidia / openai / anthropic 三家中转做备用 |

## 第 4 章 · 建机器人

**视频原流程**

1. 浏览器输入 AstrBot 后台地址（具体地址在配套文档里）
2. 用第 1 章记下的默认账号密码登录
3. 系统**强制让你设置账户** → 换成你自己的账号 → 设一个稍复杂的密码
4. 进后台 → 左侧「**机器人**」→ 点「创建机器人」
5. 消息平台类型展开 → 选 **OneBot v11**
6. 名字填「大肥鱼」→ 勾上「启用」
7. 反向 WebSocket → **主机照画面填** → **端口留默认 6199**
8. 反向 WebSocket **token** 自己敲一串密码 → 这是等会儿 NapCat 那边要对的暗号，**记下来保存**
9. 核对完点保存 → 列表里就会显示「大肥鱼 正在运行」

**本机实际**

`config/astrbot/platform.json`：

```json
{
  "id": "大肥鱼",
  "type": "aiocqhttp",
  "enable": true,
  "ws_reverse_host": "127.0.0.1",
  "ws_reverse_port": 6199,
  "ws_reverse_token": "<REDACTED>"
}
```

适配器名就叫「大肥鱼」，会话标识格式是 `大肥鱼:FriendMessage:<QQ号>`。

## 第 5 章 · 绑模型

**视频原流程**

1. 左侧点「**模型供应商**」→ 进「对话」
2. 点「新增供应商」→ 选 **DeepSeek**
3. 把记事本里的 key 粘进 API key 这一栏
4. ⚠️ **填完 key 一定要先点顶部的「保存配置」**
5. 再点「获取模型列表」，列表拉出两个模型
6. 选**又便宜又快的 DeepSeek flash** → 点保存
7. 再去「配置文件」→ 点开 AI 里的「模型」
8. 把**对话模型**和**图片转述模型**全部切成 DeepSeek flash
9. 点右下角那个**软盘小图标**保存

**本机实际**

`config/astrbot/cmd_config.json`，池子里 **7** 个供应商（5 对话 + 1 嵌入 + 1 语音）：

| id | 类型 | 实际调用次数 |
|---|---|---|
| `deepseek-responses/deepseek-v4.1-flash` | 对话 | 599（迁移前） |
| `nvidia/nvidia/nemotron-3-ultra-550b-a55b` | 对话 | 413（Agent 主循环） |
| `dp/deepseek-v4.1-flash` | 对话 | 140（迁移后） |
| `openai-responses/gpt-6.1-sol` | 对话 | 70 |
| `anthropic/claude-opus-5.5` | 对话 | 11 |
| `nvidia/nvidia/nemotron-3.5-super-vl-120b-a12b` | 对话+视觉 | 2 |
| `大肥鱼记忆-本机` | 嵌入 | 记忆用，见第 9 章 |
| `大肥鱼语音-Breeze` | TTS | 语音用，见 [../README.md](../README.md) |

视频只教了「一个 DeepSeek 供应商」。本机多配了 nvidia / gpt / claude 三条备用路线，Agent 主循环还单独交给了 nemotron —— 这部分是视频之外，见 README。

## 第 6 章 · 连起来（登录小号 + 打通）

**视频原流程**

**登录小号：**

1. 打开 D 盘 NapCat 目录下的 **show 文件夹**
2. 双击运行 napcat 脚本
3. 弹安全警告点「运行」
4. 会出现一个**二维码** → 拿手机上登录的**小号**扫一下
5. 它会刷登录数据，小号就算成功上线
6. ⚠️ **这个黑框不能关**，平常最小化就行 —— 关掉你的 DeepSeek 就跟着下线了

**让 NapCat 连上 AstrBot：**

1. 黑框里能看到 NapCat 的后台地址 → 复制进浏览器打开
2. 点左侧「**网络配置**」→ 点「新建」→ 选 **WEBSOCKET 客户端**
3. 打开「启用」
4. 名称写 `astrbot`
5. **URL 照画面填** —— ⚠️ 冒号必须是**英文标点**，**文末的斜杠不能漏**
6. 密码/token 填刚才编的那串
7. 把**心跳间隔**和**重连间隔**都改成 **1000**
8. 点保存
9. 回 AstrBot 后台「**数据与日志**」→ 在日志里搜「**适配器已连接**」
10. 能看到这一行，三样东西就成功打通了
11. 拿大号给小号随便发句消息，能正常收发就说明基础成功

**本机实际**

两种连法二选一，本机用的是 **AstrBot 侧做服务端、NapCat 主动连**。所以本机的 `napcat_protocol_<QQ号>.json` 里网络配置是**全关**的：

```json
{ "enable": false, "network": { "httpServers": [], "websocketServers": [], "websocketClients": [] } }
```

看到这个不要以为没连上 —— 连接由 AstrBot 建立，NapCat 侧不需要客户端配置。

**验证**：NapCat 目录下的 `quick-login.log` 里有 `接收 <- 私聊` 和 `发送 -> 私聊` 的行。

## 第 7 章 · 设防（调整人格之前必须先做）

**视频原流程**

视频原话：不设防的话，「只要别人加了小号的好友或者拉进群，他谁的话都能接，聊出来的费用全部算在你头上，甚至有些人会通过他套出你的个人信息」。

1. 进 AstrBot 后台「配置文件」→ 找「**访问控制**」
2. 确保「**启用白名单**」是开着的
3. 白名单 ID 列表里填**大号的会话 ID**
   - 拿法：用大号给小号发一条 `/sid`，它会把一串代码回给你 → 直接复制过来填进去
4. 点「保存配置」
5. 「**管理员 ID**」里点「添加更多」→ 填上大号的 QQ 号 → 保存
   - 视频原话：「管理员拥有最高控制权限，**这个只能留给你自己**」
6. 最后一般默认把「使用电脑」的权限**关闭**
7. 去「配置文件」→ 点开 AI 下面的「**能力**」→ 看「使用电脑能力」那一栏的「运行环境」
   - 默认是「**不允许任何环境**」—— 这样它就只能聊天，读不了你电脑里的文件、也跑不了命令

**本机实际**

`config/astrbot/cmd_config.json`：

```json
{
  "platform_settings": {
    "enable_id_white_list": true,
    "id_whitelist": [
      "大肥鱼:FriendMessage:###",
      "大肥鱼:FriendMessage:<GUEST-A>",
      "大肥鱼:FriendMessage:<GUEST-B>"
    ]
  },
  "admins_id": ["###"]
}
```

视频说「白名单只填大号」，本机多了两个访客号 —— 这是你后来自己放开的，见 README。

电脑能力本机是**按角色分级**开的（视频说默认全关，本机改成了分级）：

```json
{
  "computer_use_require_admin": true,
  "computer_use_local_permissions": {
    "member": { "allow_execution": false, "allow_network": false, "filesystem_scope": "none" },
    "admin":  { "allow_execution": true,  "allow_network": true,  "filesystem_scope": "host" }
  }
}
```

普通成员什么都干不了，管理员（你）可以执行命令、访问网络、读写全盘。

## 第 8 章 · 导入配置包（人格 + 表情包 + 语音）

**视频原流程**

视频作者把人格、插件、表情包和各项参数都调好了，做成配置包。下载地址在配套文档里。

1. 解压配置包
2. **确保 AstrBot 是开着的**
3. 双击配置包里的「**导入大肥鱼**」
4. 窗口里会一项项问你：
   - **后台地址**：一般默认填好了，直接按回车
   - **后台账号和密码**：输入第 4 章换好的
   - **QQ 大号**：填你的。视频原话「**他只会认这个号当主人**」
   - **记忆**：这一步**先选 0**（下一章会接着装）
   - **语音**：直接回车，选的就是**豆包**
   - 把第 3 章存的 **app id 和 access token** 依次粘进去
5. 豆包的语音插件导入工具会一起装好，不用再进后台设置
6. ⚠️ **第一次跑要下载插件和几百张表情包**，需要等几分钟
7. 跑完会列出每一项有没有成功
   - **哪一项打了叉，按照内行的提示再双击一次就行**
8. 最后在 QQ 上给它发一条 **`/reset`**，把刚才那段客服对话清理掉
9. 再随便跟它说一句话，回复应该就比较正常了
10. 它回消息会配表情包 —— 包里自带两套：**蓝色大肥鱼 157 张** + **DeepSeek 二创 174 张**
11. 语音也是正常通的

**装完它会变成什么样**（视频原话）：

- 会自己跑来找你说话 —— 视频作者设的是**凌晨 1 点到 7 点不主动找你**，可以自己改
- 跟它说有重要的事要提醒，它会**先问你具体哪天几点**，然后自己定好闹钟，到时候叫你
- 想让它发 QQ 空间说说或改个性签名，**直接跟它说**
- 想听它唱歌，**直接让它唱**
- 配置包**默认没开**「每天晚上让它自己发 QQ 空间记笔记」这个选项，想开的话文档里留了开关

**本机实际**

| 项 | 值 |
|---|---|
| 人格 | **3451 字**，全文 [config/personas/大肥鱼.system_prompt.md](../config/personas/大肥鱼.system_prompt.md) |
| 表情包 | 视频说两套 157 + 174，本机实际 **3 包 763 张**（多装了官方包 410 张） |
| 静默时段 | 凌晨 **1–7 点**不主动（与视频一致） |
| 语音 | **换成了本机 Breeze**，不是豆包（视频之外的选择） |

## 第 9 章 · 装记忆

**视频原流程**

**为什么会失忆**（视频原话）：

> AI 容易失忆，是因为它每次回话都得把历史记录从头看一遍，聊多了之后上下文装不下了，只能把前面的记录悄悄地扔掉。你要是顺手清理了聊天框，它更是会直接把跟你聊过的所有上下文全部忘掉，把你当做陌生人。

**解决思路**：装记忆插件，相当于**塞给它一个记事的小本子**，每次回话前都去本子里翻一翻。

**要用到一个叫「嵌入模型」的东西** —— 作用是把你说的话变成一串数字坐标，意思相近的句子挨得近，这样它才能顺藤摸瓜找到对应的笔记。

**两种接法，二选一：**

**方式一：跑在自己电脑本地（Ollama）**

1. 浏览器搜 `ollama` 进官网 → 点下载 → 安装
2. 好处：完全免费、不用联网、聊私密话题都留在你电脑里
3. 缺点：占内存，安装包 **1.5 GB**，后面还要拉模型，占你电脑配置
4. 装完打开 PowerShell，**敲一行命令**就能把模型下下来

**方式二：用硅基流动**

1. 浏览器搜「硅基流动」→ 注册登录
2. 在「模型广场」搜 `BGE-M3`
3. 能看到标着 **1024 维**的 `BAAI BGE-M3`
4. 点左边「API 密钥」→ 新建一个密钥
5. 描述写「大肥鱼的记忆」→ 建好复制出来
6. 平台上标着这个模型是**免费**的

**装完再双击一次「导入大肥鱼」：**

1. 前面几项照第 8 章再答一遍
2. ⚠️ **语音别选 0** —— 选 0 会把语音关掉
3. **记忆那一步选 1 或者 2**（选 2 的话把硅基流动的 key 填进去）
4. 这次会很快，前面装过的东西它会自己直接跳过

**本机实际**

选了**方式一**（本机 Ollama）：

```json
{
  "id": "大肥鱼记忆-本机",
  "type": "openai_embedding",
  "embedding_api_base": "http://127.0.0.1:11434/v1",
  "embedding_model": "bge-m3",
  "embedding_dimensions": 1024,
  "embedding_api_key": "ollama"
}
```

| 项 | 值 |
|---|---|
| Ollama 版本 | **0.40.14** |
| 模型 | `bge-m3`，**1.2 GB**，1024 维，8K 上下文 |
| 记忆插件 | LivingMemory **2.8.2** |
| 记忆量 | 71 篇情景记忆、295 条原子、572 个节点、2065 条边 |

本机这套**完整链路是通的**：两个 FAISS 索引都在（`livingmemory.index` 1024 维 70 条、`livingmemory_graph.index` 1024 维 62 条），用 `document_vector_provider_fingerprint` 反解确认是 `大肥鱼记忆-本机`（bge-m3）算的。Ollama 是链路第 5 步的服务，和 AstrBot/NapCat/ComfyUI 一样常驻后台，安装器会注册开机自启。

情景记忆在 11-05 和 11-06 白天停过两天，但 **11-06 20:55 又写了一篇**（重要度 0.78），索引同步从 70 涨到 71，说明链路完整。详见 [memory.md](memory.md) 第 4 节。

完整链路（写入七步 + 读取两路）见 [memory.md](memory.md) 第 3 节。

## 第 10 章 · 交给 AI 帮手

**视频原流程**

如果你电脑上本来就装了能操作系统的 AI 帮手（比如 **DeepSeek Harness**），前面这些点来点去的繁杂操作**大部分都可以让它来代劳**。

做法：把作者写好的**提示词直接粘给它**。提示词分四段：

| 段 | 让它干什么 |
|---|---|
| 第一段 | 从零把 AstrBot、NapCat、DeepSeek 串起来，配置好安全权限 |
| 第二段 | 自动导进大肥鱼的配置 |
| 第三段 | 装记忆模块 |
| 第四段 | 帮你改性格 |

发出去之后，AI 帮手就会在你的屏幕上操作。

**视频实测耗时**：导入配置包 **2 分多钟**，装记忆 **6 分钟**，改性格**不到 4 分钟**。

**但仍需你手动介入**：登录 QQ、Windows 弹窗确认、开放平台的 API Key。

**本机实际**

## 常见问题（视频里的问答）

**性格和说话方式在哪里改**

写在后台的**人格设定**里，是一段普通的**大白话**，直接改那段文字就行。也可以让你的 AI 帮忙改。

**表情包或语音发得太多/太少**

它们各自都有一个**频率**参数，文档里有对照表，照着调。

**嫌豆包想得慢或者不想花钱**

重新运行一次导入工具，**语音选 Edge** —— 它是免费的，代价是声音有点机械。

**改完人设，QQ 里没有变化**

发一条命令还不行的话，去后台的**绘画配置**里看看：这个对话是不是**单独绑了别的配置**。

**两个最典型的报错**

| 现象 | 原因 | 处理 |
|---|---|---|
| 部署时 **403** | 加速镜像站跳转被拦截 | 点重试；还不行就**关掉一键加速**再部署一次 |
| 后台**连不上** | 反向 WebSocket 地址有问题 | 查三样：冒号是不是打成**中文冒号**、末尾有没有**漏斜杠**、两边的 **token 是否一致** |

**花销**

一般来说**私聊更便宜**；拉进群或者发图给它看会**贵一些**。可以在 DeepSeek 控制台看到每天的花销是多少。

**能不能接到别的平台**（视频说这三家都没实测）

| 平台 | 情况 |
|---|---|
| 抖音私信 | AstrBot 有插件，但别人实测**大约 10 分钟就会弹手机号验证** |
| B 站 | 风控加强了，登录小号要实名认证，作者没实测成功 |
| 微信 | 官方通道只能你跟他聊、**不能发语音、不能主动找你**；桌面模拟会触发微信风控，可能限流或掉登录 |
