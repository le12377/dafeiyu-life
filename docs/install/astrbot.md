# 安装 AstrBot

这一节把「下载 Launcher → 开一键加速 → 装三个组件 → 创建实例 → 拿到账号密码」拆开讲。

## 0. 官方地址

| 用途 | 地址 |
|---|---|
| **发布页（下载在这）** | https://github.com/AstrBotDevs/AstrBot/releases |
| 仓库主页 | https://github.com/AstrBotDevs/AstrBot |
| 官方文档 | https://docs.astrbot.app |
| 插件市场 | 后台左侧「插件市场」直达 |

组织名 **AstrBotDevs**，仓库 **AstrBot**。

## 1. 下载启动器

打开发布页 https://github.com/AstrBotDevs/AstrBot/releases ，在最新一版的 **Assets** 里找 **AstrBot Launcher**（Windows 桌面版 `.exe`）。

**别下这些**：

| 资产 | 是什么 | 什么时候用 |
|---|---|---|
| `AstrBot-v4.29.x-dashboard.zip` | 纯源码 + 前端 | Docker 部署、Linux 手动装 |
| Docker 镜像 | 容器版 | 云服务器 |
| **AstrBot Launcher `.exe`** ✅ | **Windows 桌面版，一键装** | **本地 Windows，要的就是它** |

发布页里每个版本都有 `dashboard.zip`（本机 `version_list.json` 拉到的就是这种，5MB 左右），但它**不是给 Windows 初学者用的**——它需要你自己配 Python、装依赖、跑 `main.py`。Launcher 把这些全包了。

下载下来是一个 `.exe`，双击安装。Windows 大概率会弹出蓝色的 SmartScreen 警告，因为安装包没有微软签名：

1. 点弹窗里的「**更多信息**」
2. 点「**仍要运行**」
3. 安装位置**用默认的就行**，别改到中文路径或带空格的怪路径下

装完打开，会看到一个启动器窗口。

## 2. 开一键加速

启动器左侧有个「**高级**」（Advanced）页，里面有一项「**中国大陆一键加速**」。

- 打开它，后续下载组件和部署实例会走镜像
- 这个开关是给国内网络用的，如果你本身能直连 GitHub 和 PyPI，也可以不开

**什么时候要关掉它**：部署时如果遇到 403 错误，多半是加速镜像跳转被拦截。先点重试，还不行就把一键加速关掉，再部署一次。

## 3. 装三个组件

左侧「**组件管理**」页，里面有三个组件，每个都要点一次「下载」，等进度条走完：

| 组件 | 本机装的版本 | 作用 |
|---|---|---|
| Python | **3.10.22** 和 **3.12.16**（两个都有） | 跑 AstrBot 本体 |
| Node.js | **v26.13.0** | 跑 Dashboard 前端、MCP 服务（`npx mcp-remote` 那条路要用） |
| uv | **0.13.6** | 装 Python 依赖，比 pip 快很多 |

**关于 Python 版本**：AstrBot v4.29.1 的更新日志里写了，从 2026-11-01 起停止支持 Python 3.12 之前的版本。本机两个都装了，实际实例用的是 **3.12.16**。如果你的启动器只给一个版本，选新的那个。

组件装好后会落在启动器的 `components/` 目录下，结构是：

```
components/
├── python/
│   ├── py310/python.exe     ← 3.10.22
│   └── py312/python.exe     ← 3.12.16
├── nodejs/
│   ├── node.exe             ← v26.13.0
│   └── node_modules/
└── uv/
    └── uv.exe               ← 0.13.6
```

**排查**：如果某个组件下载卡住，去看启动器上的进度条有没有动。没动就关掉该组件重下一次。三个组件的包都不小（Node 的 exe 单文件就有 100MB）。

## 4. 创建实例

组件装完，点「**创建实例**」，会弹出几个输入项：

| 字段 | 填什么 | 本机实际 |
|---|---|---|
| 名字 | 随便取，只用于显示 | （自定） |
| 版本 | 下拉里选最新的**正式版**，别选 beta | **v4.29.4** |
| 端口 | **留空**，自动分配 | 自动 |

点「部署」，然后**等**。这一步要在实例目录里建 venv、装几十个 Python 依赖（`aiohttp`、`anthropic`、`faiss-cpu`、`sqlalchemy` 等等），通常要好几分钟，慢的时候十几分钟。

部署期间不要关启动器。

**部署完成**时会弹出一组**后台默认账号和密码**。这一组一定要存下来，比如抄到记事本：

- 默认用户名是 `astrbot`
- 默认密码，如果没设环境变量，是 `astrbot`（源码里的 `DEFAULT_DASHBOARD_PASSWORD`）
- 但**第一次启动时**，AstrBot 会自己生成一个 **24 位**的随机密码，大写+小写+数字各至少一个，然后写进 `cmd_config.json` 的 `dashboard.password`（存的是哈希）

所以你看到的那个弹窗里的密码，是**真正能用的那一个**。丢了就只能重置：

```powershell
# 方式一：启动前设这个环境变量，下次启动会用它当初始密码
$env:ASTRBOT_DASHBOARD_INITIAL_PASSWORD = "你的新密码"

# 方式二：强制重置
$env:ASTRBOT_RESET_DASHBOARD_PASSWORD = "1"
```

**密码强度**：最少 8 位。哈希用的是 PBKDF2-HMAC-SHA256，60 万次迭代、16 字节盐。

部署成功后，实例会出现在启动器列表里，卡片下面有一排图标。下一节点 **①** 启动、点 **③** 进后台。

## 5. 实例目录长什么样

部署成功后，实例落在：

```
instances/<实例UUID>/
├── core/                    ← AstrBot 主程序
│   ├── astrbot/             源码
│   ├── main.py              入口
│   ├── requirements.txt     依赖清单
│   ├── data/                ★ 所有配置和数据库都在这
│   │   ├── cmd_config.json    主配置
│   │   ├── data_v4.db         主数据库
│   │   ├── config/            插件配置
│   │   ├── plugins/           插件源码
│   │   └── workspace/         生成的图
│   └── dashboard/           前端静态资源
└── venv/                    ← 专属 Python 环境（3.12.16）
    ├── pyvenv.cfg
    └── Scripts/
```

**记住那个实例 UUID**。后面看日志、改配置、备份，全都要用这个路径。

本机实例 UUID 是 `<INSTANCE_ID>`，版本目录里还留着 `v4.29.3.zip` 和 `v4.29.4.zip`（启动器下载的安装包缓存）。

## 6. 首次启动

实例部署完，启动器上那个实例卡片底下会有一排图标。**这排图标就是日常操作的全部入口**。

![Launcher 实例工具条](images/launcher-toolbar.png)

从左到右七个图标：

| 序号 | 图标 | 作用 | 常用度 |
|---|---|---|---|
| ① | 圆形暂停/停止 | **启动 / 停止实例** | ★★★ 最常用 |
| ② | 循环箭头 | 重启 | ★★ |
| ③ | 地球 | **打开 Web 后台**（浏览器自动跳转） | ★★★ 最常用 |
| ④ | 文件夹 | 打开实例目录（直接跳到 `core/`） | ★★ |
| ⑤ | 文档 | 查看日志 | ★★ |
| ⑥ | 齿轮 | 实例设置 | ★ |
| ⑦ | 垃圾桶 | 删除实例 | ⚠️ 少碰 |

**正常使用只有两个动作：点 ① 启动，等它起来，再点 ③ 进后台。**

完整流程：

1. 点 **①**（暂停/播放那个圆图标）启动实例
2. 等状态变成运行中。首次启动会慢一些，要初始化数据库、加载插件
3. 点 **③**（地球图标），浏览器会自动打开后台页面

后台地址是：

```
http://127.0.0.1:6185
```

端口号看 `cmd_config.json` 里的 `dashboard.port`。默认绑 `0.0.0.0`，也就是局域网里别的机器也能访问——不想要这个行为就改成 `127.0.0.1`。

用弹窗里那组账号密码登录，**系统会强制你改一次密码**（`password_change_required`）。改成你自己的，别留默认。

### 几个图标的使用场景

**④ 文件夹**：点它直接跳到实例的 `core/` 目录。改配置、备份数据库、看 `data/` 都在这里，比自己在资源管理器里找路径快。

**⑤ 文档**：实例起不来的时候先点这个。常见的启动失败（端口占用、依赖缺失、配置 JSON 语法错）都能在这看到具体报错。

**⑦ 垃圾桶**：删实例是**不可恢复**的，`core/data/` 整个没了。手滑点到的代价是所有聊天记录、记忆、插件配置一起消失。删之前一定先备份 `core/data/`。


## 7. 升级

启动器会定期拉版本列表。本机 `version_list.json` 里有最近 30 个版本，最新是 **v4.29.4**。

升级注意：

- 升级前**先备份** `core/data/`，尤其是 `cmd_config.json` 和几个 `.db`
- 大版本升级会迁移配置结构（比如 v4.29.0 把「管理员/白名单」从「配置文件→平台」挪到了「配置文件→访问控制」，「文转图」从「设置」挪到了「配置文件→扩展功能」），迁移后旧路径找不到选项是正常的，按新路径找
- 不要在实例运行中直接替换文件，用启动器的升级功能

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 部署卡在 403 | 加速镜像跳转被拦 | 点重试；还不行就关掉一键加速再部署 |
| 部署失败没反应 | 依赖装到一半断了 | 删掉实例重建；或者进 `venv` 手动 `pip install -r requirements.txt` |
| 后台打不开 | 端口被占 / 没启动 | `Get-NetTCPConnection -LocalPort 6185` 查占用 |
| 密码忘了 | 生成的 24 位随机密码丢了 | 用上面两个环境变量重置 |
| Python 版本报错 | 用了 < 3.12 | 换 3.12.16 |
| 组件下载失败 | 网络 | 开一键加速，或挂代理 |
